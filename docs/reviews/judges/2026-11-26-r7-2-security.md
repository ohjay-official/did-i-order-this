Pasted/mixed/flagged/fixture all cap at Neutral; lookalike domains rejected by `normalizeDomain`/`findOfficialDomain`; manual tracking field cannot plant unless attacker knows user-typed number; `canSaveShipmentFromClaim` requires verified sender + exact vetted DMARC `p=reject` domain + no risky ask/off-platform/hidden/unread content + no outside link or image hosts; r6-F2 fix for `expectedUntil` verified via `round6.test.ts` + P9; `target.com` and `bestbuy.com` correctly off the vetted list (confirmed in `web/src/packs/official.json`, 14 entries).

3. **Secrets**: `.env.example` empty; full `git log --all -p` scan with the seven patterns from `scripts/verify.mjs:36-44` returns zero hits outside the detector itself.
4. **XSS**: every `innerHTML` sink found (`InboxApp.ts`, `consentDialog.ts`, `shell.ts`, `landing.ts`, `belt.ts`, `fixture.ts`, `sidepanel.ts`) wraps user data in `escapeHtml`/`esc`. CSP: no `unsafe-inline` or `unsafe-eval` in scripts, `object-src 'none'`, `frame-ancestors 'none'`.
5. **Extension messaging/storage**: r6-I1 fixed (`background.ts:114` rejects `GET_EMAIL` when `sender.tab` is present); `isTrustedSender` rejects extension-id mismatch and `mail.google.com.evil.example`; `sanitizeEmail` type-checks every field, caps `linkHosts`/`imageHosts` to 200, lowercases hosts, filters `gmailFlags` to whitelist; background rewrites `email.fixture` authoritatively; entries cleared on last panel disconnect.
