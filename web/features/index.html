Features

What you can do today

These are the features that ship now. Nothing here is a roadmap item presented as finished.

The rule that matters

A carrier email is judged by the tracking number you already have, not by how official it looks.

If the number matches an expected parcel

Code marks the check Safe.

If it does not

Code marks the check Warning, even when the domain looks official.

Store and billing mail

Those are checked by the cited order or invoice number, not by a scam score.

Orders stored on this device

Orders, shipments, and known senders stay in IndexedDB in this browser, or in chrome.storage.local in the extension. The demo set can be reset. You can save a shipment after a check.

On-device import

Import an Amazon Retail.OrderHistory CSV or ZIP, a PayPal activity CSV, or a generic CSV. Parsing happens locally. Jumia, Walmart, and Shopify customer exports are not supported.

A visible hybrid label

Each finished check shows whether it ran on the device, in the cloud after you agreed, as a limited check with no AI, or was not completed.

Consent before cloud inference

The default is on-device only. If on-device AI is missing, the hosted site asks before sending the email off the device. The extension does not send mail to the cloud.

A Chrome side panel for Gmail

The extension reads the open Gmail thread as text and runs on-device AI only. Cloud checks go through the hosted site after you agree. The extension is not in the Chrome Web Store yet.
