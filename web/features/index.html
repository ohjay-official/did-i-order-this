Structured claim the model is allowed to produce

Claims to be DHL, as a carrier

Claimed domain: dhl-parcel-desk.example
Asks you to: pay a release fee
Cites: tracking GM123456789012345
Email kind: carrier_update

The model reads the claim. Code issues the verdict.

Firebase AI Logic is asked only to structure what the email claims. Deterministic code compares that claim with the records on this device.
