Features

What you can do today

These are the features that ship now. Nothing here is a roadmap item presented as a finished product.

A ledger on this device

Orders, shipments, and known senders stay in IndexedDB in this browser, or in chrome.storage.local in the extension. The demo ledger can be reset. You can save a shipment after a check.

Carrier and store rules

Carrier emails are checked by tracking number. Store, invoice, and renewal emails are checked by the cited order or invoice number. The verdict comes from code, not from a scam score.

On-device import

Import an Amazon Retail.OrderHistory CSV or ZIP, a PayPal activity CSV, or a generic CSV. Parsing happens locally. Jumia, Walmart, and Shopify customer exports are not supported.

A visible hybrid label

Each finished check shows whether it ran on the device, in the cloud after you agreed, as a limited check with no AI, or was not completed.

Consent before cloud inference

The default is on-device only. If Nano is missing, the hosted site asks before sending the email off the device. The extension does not send mail to the cloud.

A Chrome side panel for Gmail

The extension reads the open Gmail thread as text and runs on-device AI only. Cloud checks go through the hosted site after you agree. The extension is not in the Chrome Web Store yet.
