About

Built to check a parcel claim against what you ordered

Did I Order This? is a delivery-scam guard for email. It was built by Oh-Jay as an entry for #BuildHybridAI 2026, the Firebase AI Logic hybrid inference hackathon.

The problem

A delivery, renewal, invoice, or refund email can ask you to pay a fee or click a link. Without a way to check that claim against purchases and tracking numbers that never leave your laptop, a fake parcel message looks like a real one.

The approach

On-device AI reads what the email claims. Deterministic code checks that claim against the orders stored on the device. Cloud inference is a fallback you can refuse. All model calls go through Firebase AI Logic, not through a raw browser Prompt API in the product.

Who it is for

Anyone who gets carrier and billing email in a browser, including judges who need to try a demo without a Gmail login. The hosted sample inbox is the public path. The Chrome extension is for an open Gmail thread on a laptop that can run on-device AI.
