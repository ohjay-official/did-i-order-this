How to sideload it

These are the steps as they work in Chrome today.

01

Get the unpacked build

Use the extension folder from the public repository. There is no store button to click yet.

github.com/ohjay-official/did-i-order-this

Unpacked extension build

The package is not in the Chrome Web Store yet. You sideload the unpacked build from the repository's extension folder.

02

Load it in chrome://extensions

Turn on Developer mode, choose Load unpacked, and select that folder.

chrome://extensions

Developer mode, then Load unpacked

Turn on Developer mode in the top right, choose Load unpacked, and select the extension folder.

03

Open a Gmail thread, then the panel

The side panel reads only the message that is open. Cloud checks are not run here. Use the hosted site if you want to allow a cloud check.
