Chrome extension

Check the open Gmail thread on this device

The extension is a side panel for Chrome. It reads the email you already have open, runs on-device AI, and keeps the ledger in chrome.storage.local.

What it does

A content script extracts text from the open Gmail thread. The side panel runs the same claim-and-ledger check as the hosted site, in on-device mode only. You can import order history and run a limited check if on-device AI is not available.

What it does not do

  • It does not send mail to the cloud.
  • It does not request gmail.readonly or any other Gmail OAuth scope.
  • It does not scan the mailbox on install.
  • It is not listed in the Chrome Web Store yet. Sideloading the unpacked build is how it is loaded today.

If you want a cloud check

Open the hosted site, agree to a cloud check there, and use the sample inbox or paste the same question into that flow. The extension will point you to the hosted checker instead of sending the thread itself.

On-device AI in Chrome needs a desktop browser that can run Gemini Nano, typically a machine with enough memory for the on-device model. The hosted sample inbox is the path that works without installing anything.
