Install

Four steps, about a minute

  1. 01

    Download

    Get did-i-order-this-extension-0.1.0.zip from this page.

  2. 02

    Unzip it

    Extract the zip to a folder you will keep. Chrome loads the extension from that folder.

  3. 03

    Load unpacked

    Open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the unzipped folder.

  4. 04

    Open a thread

    Open a Gmail thread, then the side panel. It reads only that message, with no Gmail API access and no mailbox scan.

Desktop Chrome only. On-device AI needs a computer that can run Gemini Nano in Chrome. Phones can use the hosted sample inbox, which asks before any cloud check.
